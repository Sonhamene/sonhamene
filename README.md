## 🚀 Projetos

### 🌍 [GeoChute](https://github.com/sonhamene/geochute)

Jogo inspirado no **GeoGuessr**, desenvolvido como um **userscript para Tampermonkey** e executado dentro do **Google Maps**.

Explore o mundo, receba desafios e teste seu conhecimento geográfico direto no Maps.

**Como instalar:**
1. Instale a extensão [Tampermonkey](https://www.tampermonkey.net/)
2. Abra o repositório do [GeoChute](https://github.com/sonhamene/geochute)
3. Instale o userscript
4. Abra o Google Maps e jogue
